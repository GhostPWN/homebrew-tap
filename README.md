# GhostPWN Homebrew Tap

This repository is the single source of truth for the GhostPWN Homebrew formula in `Formula/ghostpwn.rb`.

Install GhostPWN with Homebrew:

```bash
brew install GhostPWN/tap/ghostpwn
```

This command trusts the `ghostpwn` formula. If Homebrew reports an untrusted tap
for an older install, trust the formula and upgrade:

```bash
brew trust --formula GhostPWN/tap/ghostpwn
brew upgrade ghostpwn
```

Run the TUI:

```bash
ghostpwn
```
